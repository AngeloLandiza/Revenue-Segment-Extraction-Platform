# Documentation Index

This folder is the detailed reference set for reviewers running the Streamlit prototype locally
or on Streamlit Community Cloud. The root `README.md` is the GitHub repository landing page.

## Start Here

- `SOLUTION_DESCRIPTION.md`: concise product and implementation overview.
- `PIPELINE_WALKTHROUGH.md`: numbered end-to-end pipeline from configuration to export.
- `DEMO_SCRIPT.md`: guided demo flow for presenting the prototype.
- `MANUAL_TEST_CHECKLIST.md`: manual verification checklist.
- `ARCHITECTURE_DECISIONS.md`: decision log for every implementation prompt.

## Data, API, And Export Contracts

- `DATA_CONTRACT.md`: core data fields and table meanings.
- `API_CONTRACT.md`: stable API-style response schemas.
- `EXPORTS.md`: CSV, XLSX, and audit JSON behavior.
- `VALIDATION_AND_RECONCILIATION.md`: validation rules, reconciliation checks, and review impact.

## Pipeline Modules

- `PARSING_AND_RETRIEVAL.md`: deterministic PDF parsing and candidate page retrieval.
- `LLM_EXTRACTION.md`: strict-schema LLM extraction workflow.
- `PROMPTS.md`: prompt behavior and schema expectations.
- `NACE_MAPPING.md`: NACE Rev.2 mapping flow.
- `ESG_EXTRACTION.md`: ESG extraction and review.
- `SCORING_MODEL.md`: demonstration scoring model.
- `OCR_AND_MULTILINGUAL.md`: OCR and multilingual handling.

## Operations And Evaluation

- `STREAMLIT_COMMUNITY_CLOUD.md`: deployment setup for Streamlit Community Cloud.
- `TESTING_STRATEGY.md`: automated and manual test strategy.
- `EVALUATION.md`: gold-set evaluation workflow.
- `PERFORMANCE_ANALYSIS.md`: runtime and quality considerations.
- `PIPELINE_PRESENTATION_GUIDE.md`: implementation talking points for reviewers.
- `IMPLEMENTATION_PLAN.md`: project implementation roadmap.
- `REFLECTION.md`: retrospective notes.
